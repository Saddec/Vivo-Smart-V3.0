# Vivo-Smart V3.0 (ESP32-S3)
        مشروع متطور لإدارة مواقيت الصلاة وتشغيل الأذان آلياً باستخدام ESP32-S3.

        ## المميزات:
        - **Multi-Core Processing:** استخدام FreeRTOS لتوزيع المهام (الصوت على نواة، والنظام على نواة).
        - **Modular Code:** الكود مقسم لسهولة التعديل (Audio, WebServer, Scheduler, GPIO).
        - **Web Dashboard:** واجهة تحكم كاملة لإدارة الملفات والمواقيت.

        ## الهيكل البرمجي:
        - `AudioTask`: معالجة الصوت I2S.
        - `VivoWebServer`: واجهة الويب والـ API.
        - `Scheduler`: نظام جدولة التنبيهات.
        ```

### الخطوة 2: إنشاء مستودع (Repository) على GitHub
1.  افتح حسابك في [GitHub](https://github.com/).
2.  اضغط على علامة **(+)** واختر **New repository**.
3.  اسم المستودع: `Vivo-Smart-V3.0`.
4.  اجعله **Public** (ليراه الجميع) أو **Private** (لك فقط).
5.  **لا تضغط** على خيار "Add a README file" (لأننا أنشأناه يدوياً).
6.  اضغط **Create repository**.
7.  ستظهر لك صفحة بها رابط ينتهي بـ `.git` (انسخه).

---

### الخطوة 3: رفع الكود باستخدام Terminal (داخل VS Code)
افتح الـ Terminal في PlatformIO ونفذ الأوامر التالية بالترتيب:

1.  **تفعيل Git في مشروعك:**
    ```bash
    git init
    ```

2.  **إضافة جميع الملفات:**
    
```bash
    git add .
    ```

3.  **تثبيت التغييرات (Commit):**
    
```bash
    git commit -m "First Success Build: Organized Modular Structure"
    ```

4.  **تسمية الفرع الرئيسي (Main Branch):**
    ```bash
    git branch -M main
    ```

5.  **ربط مشروعك المحلي بمستودع GitHub:** (استبدل الرابط بالرابط الذي نسخته من الخطوة السابقة).
    
```bash
    git remote add origin https://github.com/YourUsername/Vivo-Smart-V3.0.git
    ```

6.  **الرفع النهائي:**
    ```bash
    git push -u origin main
    ```
