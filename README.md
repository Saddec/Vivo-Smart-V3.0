# Vivo Smart Controller

تطبيق Flutter للتحكم الذكي بنظام Vivo Smart للصوت ومواقيت الأذان.

## الميزات

- تسجيل الدخول والاتصال بجهاز Vivo Smart عبر IP
- **مسح IP للشبكة**: البحث التلقائي عن أجهزة Vivo Smart في الشبكة المحلية
- لوحة تحكم رئيسية مع عرض الوقت والتاريخ الهجري والميلادي
- عرض مواقيت الصلاة مع مؤقت تلقائي
- التحكم في مستوى الصوت
- إدارة الملفات على بطاقة SD (رفع، حذف، إعادة تسمية)
- المشغل السريع للملفات الصوتية
- إدارة التنبيهات المجدولة
- مخططات GPIO
- وضع العيد مع التكبيرات
- تنبيهات المغرب
- إعدادات Wi-Fi
- تغيير كلمة المرور
- سجل الأحداث (System Logs)

## هيكل المشروع

```
lib/
├── main.dart                 # نقطة الدخول للتطبيق
├── providers/
│   └── app_state.dart        # مزودات Riverpod وحالات التطبيق
├── screens/
│   ├── login_screen.dart     # شاشة تسجيل الدخول مع مسح IP
│   └── dashboard_screen.dart # لوحة التحكم الرئيسية
└── services/
    └── api_service.dart      # خدمة API للتواصل مع الجهاز
```
